# Share card font assets

The three WOFF2 files in `fonts/` are copied from the coordinator's approved share-preview source bundle. Their original preview stylesheet identifies them as the Google Fonts optimized font files for Inter (`e4af272ccee01ff0-s.p.woff2`), Merriweather (`1f3fe8c6df3d47c1-s.p.woff2`), and JetBrains Mono (`bb3ef058b751a6ad-s.p.woff2`). The files are retained as provided so the local renderer uses the same visual output as the approved preview.

Each family is distributed under the SIL Open Font License 1.1. The corresponding full copyright/license text is bundled under `fonts/licenses/`:

- Inter: [`fonts/licenses/Inter-LICENSE.txt`](fonts/licenses/Inter-LICENSE.txt); upstream: <https://github.com/rsms/inter/blob/master/LICENSE.txt>
- Merriweather: [`fonts/licenses/Merriweather-OFL.txt`](fonts/licenses/Merriweather-OFL.txt); upstream: <https://github.com/SorkinType/Merriweather/blob/master/OFL.txt>
- JetBrains Mono: [`fonts/licenses/JetBrains-Mono-OFL.txt`](fonts/licenses/JetBrains-Mono-OFL.txt); upstream: <https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt>

If a later source bundle uses a different family or version, recheck and update the provenance and license record before redistribution.
