## Acceptance gates

- All existing valid code forms can be applied on active notice flow; no silent loss from navigation, reload, stage resume or tier change.
- List minus discount equals server payable for 1295/1995/2795 tier quotes; zero-total order never creates paid capture; actual postage cost stays reportable.
- Two concurrent buyers cannot reserve last redemption/budget twice; retry commits only once; late capture is honored and reported.
- Rejected/expired offer has reason and normal checkout recovery; post-lock price change requires human reconfirmation/new attempt.
- No WELCOME10 or $2-off claim without validation; original channel remains available after recovery touch.
