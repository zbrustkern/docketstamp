## Acceptance gates

- Every displayed metric opens exact same-scope evidence and definition; totals match fixture oracle including >50 orders, missing joins and repeats.
- Missing spend/cost means unavailable; zero records/zero denominators produce truthful n/d and null rates; currency totals never combine implicitly.
- Replay twice yields identical projection hash and no postal/email/payment/ad invocation; old missing milestones remain missing.
- Shadow differences classify expected correction vs defect; unexplained cash discrepancies prevent publish. Reports paginate and do not scan all orders on each request.

For each task record implementation commit, changed files, exact command/result, environment/mode, expected-versus-observed oracle and redacted evidence path in progress.json. Failed or unavailable checks remain explicit; code presence alone is not verification. Obtain an independent review before marking the sprint complete.
